# Legacy
Данный репозиторий содержит мои учебные проекты за 1-2 курсы учёбы \
На направлении 01.03.02 - прикладная математика и информатика \
В Университете ИТМО

## Описание cpp-intro

Репозиторий содержит учебные и pet-проекты на C++, разработанные в рамках изучения:
- системного программирования
- структур данных
- STL
- низкоуровневой работы с памятью
- архитектуры компиляторов и интерпретаторов

В проектах реализованы собственные контейнеры, математические структуры, bitset, элементы работы с assembler и пользовательские библиотеки, приближенные к поведению STL.

## Структура проекта

```text
Legacy/
├── asm/                # длинная арифметика на ассемблере
├── bitset/             # собственная реализация bitset
├── matrix/             # реализация матриц и операций над ними
├── repl/               # REPL/interpreter experiments
├── socow-vector/       # small-object-optimized vector
├── vector/             # собственная реализация vector
└── README.md
```

## Реализованные компоненты

### Контейнеры и структуры данных
- собственная реализация `vector`
- small-object optimization для контейнеров
- реализация `bitset`

### Математические структуры
- работа с матрицами
- операции линейной алгебры

### Системное программирование
- эксперименты с assembler
- управление памятью
- работа с low-level оптимизациями

### Архитектурные эксперименты
- REPL/interpreter prototypes
- обработка пользовательского ввода
- модульная организация кода

## Используемые технологии

- C++
- STL
- Templates
- OOP

- Memory management
- Low-level optimization
